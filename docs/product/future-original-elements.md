# Future Original Elements

## Goal

After the basic server is credible, add original gameplay inspired by
`lkjmcsmp` while preserving vanilla behavior as the baseline.

## Candidate Systems

- Point economy backed by server-owned ledgers.
- Temporary dimension instances.
- Player profile and achievement surfaces.
- Party and social commands.
- Server-side HUD and action-bar orchestration.

## Rules

1. Original systems must be modular.
2. Original systems must not be required for vanilla login.
3. Economy and dimension systems require persistence first.
4. Public extension APIs are designed only after internal hooks survive load.
